# AFTERFALL

AFTERFALL is a multiplayer adventure/action RPG.

## Project Structure

- `map_generator/` — Generates `.afmap` world files
- `server/` — Game server
- `client/` — Game client
- `tests/` — Tests
- `docs/` — Design and protocol documentation

## Map Format

AFTERFALL uses the `.afmap` format for static world data.

Generated maps are not committed to Git.
